---
title: Add or edit notes/shapes on a canvas document
keywords: canvas, note, shape, sticky, stroke, board
---

Canvas documents are JSON snapshots:
{"version":1,"shapes":[...],"strokes":[...]}.

Every shape uses this structure:
{"id":"shape-...","type":"note","frame":{"x":0,"y":0,"width":240,"height":150,"rotation":0},"style":{"color":"#fef3c7"},"data":{"text":"Note"},"updatedAt":1718000000000}

Common types include `note`, `text`, `section`, `image`, `video`, `audio`,
`link`, `document`, and `file`. Type-specific values belong in `data`.

1. Read the live canvas with `get_current_document` or `read_document`. Choose a
   free position and note the current array indexes.
2. Add a note with a unique ID and current millisecond timestamp:
   {"documentId":"<id>","operations":[{"op":"push","path":".shapes","value":{"id":"shape-note-1718000000000","type":"note","frame":{"x":300,"y":100,"width":240,"height":150,"rotation":0},"style":{"color":"#fef3c7"},"data":{"text":"Hello"},"updatedAt":1718000000000}}]}
3. Edit fields through their nested paths and bump `updatedAt` in the same call:
   {"documentId":"<id>","operations":[{"op":"set","path":".shapes[2].data.text","value":"Updated text"},{"op":"set","path":".shapes[2].updatedAt","value":1718000001000}]}
4. Remove a shape by its current array index:
   {"documentId":"<id>","operations":[{"op":"unset","path":".shapes[2]"}]}
5. Re-read after every mutation because indexes can change concurrently.

Note colors: `#fef3c7` yellow, `#dcfce7` green, `#dbeafe` blue,
`#fae8ff` purple, and `#fee2e2` red. Changes are applied through Yjs and appear
live to users viewing the canvas.
