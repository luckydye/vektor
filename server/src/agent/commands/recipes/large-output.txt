---
title: Handle output too large for one tool result
keywords: large, output, truncated, pagination, jq, file
---

Most tool output is capped at about 6000 characters; `list_documents` has a
larger 30000-character allowance. When output is truncated:
- Structured tools: narrow the query or lower `limit`, then continue with
  `nextCursor`. Truncated results preserve the response tail so pagination
  metadata remains visible.
- Shell commands: rerun through `bash` and redirect to a file:
    command > out.json
  Then inspect only the needed portion with shell tools such as `wc`, `sed`,
  or `jq`.
- For paginated APIs, process one page at a time rather than combining the
  entire result in model context.
