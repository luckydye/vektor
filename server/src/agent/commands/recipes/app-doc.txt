---
title: Create or update an HTML app document
keywords: app, iframe, html, application, widget
---

Type "app" documents are full HTML apps rendered in a sandboxed iframe.
Keep CSS and JavaScript inline unless the app deliberately loads public assets.

1. Read an existing app with `read_document` or `get_current_document`.
2. Create one with `write_document` using complete HTML, a title, and type `app`:
   {"title":"My App","type":"app","content":"<!doctype html><html>...</html>"}
3. Update an app by calling `write_document` with its document ID and the complete
   revised HTML.
4. Read it again to verify the stored source.

Do not use `edit_document` on app documents. That partial-edit route sanitizes
HTML and can remove the app's `<script>` elements. Always preserve the complete
working source and replace it atomically with `write_document`.
